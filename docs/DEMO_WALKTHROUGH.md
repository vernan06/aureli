# Aureli local demo walkthrough

Launch Aureli with `.venv\Scripts\streamlit.exe run streamlit_app.py`, then choose **Continue in guest demo mode**. The guest workspace starts empty and is deleted when the guest session ends.

1. **Overview:** inspect current month income, expense, surplus, recorded loan principal, cash-flow chart, savings progress, budget watch, and guidance. Empty areas remain clearly labeled.
2. **Financial Planner → Transactions:** add a monthly income and a few categorized expenses. Edit or remove a transaction from the ledger. Return to Overview to see the totals update.
3. **Budgets:** create a monthly groceries or rent limit. The spent and remaining values use the saved transactions for the current month.
4. **Savings Goals:** create a goal, record a dated contribution, and inspect its contribution history and progress.
5. **Settings:** save a typical monthly income and emergency-fund amount. Add an obligation such as rent and pause/reactivate it.
6. **Loan Simulator:** add a loan to view the amortization schedule, record a lender-confirmed principal component, and inspect remaining principal. Compare snowball and avalanche strategies; the comparison does not alter the saved loan.
7. **Financial Twin:** adjust income, expenses, planned savings, new borrowing, or extra repayments. The projected surplus, EMI, debt-to-income ratio, and savings are calculations only; saved records remain unchanged.
8. **Reports:** download a CSV with saved transactions, totals, budgets, goals, loans, payment history, and recurring obligations.
9. **EMI Prediction and Model Laboratory:** while the specified dataset rights remain unresolved, both surfaces explain that there are no product models or results. The test suite exercises training mechanics with a generated fixture, which is never shown as a product result.
10. **End guest session:** guest data is removed. A regular account is also available for longer local use.

This document describes a live local UI journey, not a recorded video. No demo video file is included.
